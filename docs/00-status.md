# 验证状态

截至 2026-11-07 的记录，不是对设备状态的持续监控。

## 确认成功

- 音量：真实范围 0～100，短按每次 1，长按连续调整，松开停止；实体遥控器确认。
- Home：不经过厂商选择器，直接返回第三方当贝桌面；两类 HOME intent 均登记持久默认项。
- 启动：做过整机重启后的键位、服务绑定、桌面、后台属性读回；之后用户确认音量和 Home 两项正常。
- 任务清理：移除工具界面任务后服务继续运行；模拟自身无障碍启用项丢失，约 3～11 秒恢复。
- 光源：正常 1～10 档，1→10→1 保持 30 秒的实际光强变化由实体观察确认。
- 语音：调光源、打开应用、有反馈，之后悬浮面板和头像自动消失；用户确认。
- 语音持久化：重启和原助手进程重启后，新 PID、补丁版本、启动标识均匹配；临时诊断入口停止。
- 屏幕：断开 ADB 后，按 Home 回系统只亮显示器，手动选 HDMI 1 只亮投影仪；用户确认往返正常。
- 屏幕后台：电脑程序重新启动后重新发现投影仪，登录自启项已读回。

## 没有完成或不能据此推断

- Apple TV 正片仍无法播放，没有许可证错误码证明唯一根因。
- v5 的新增语音信号源命令只完成代码加载，没有完成新的实体语音测试；该任务随后停止。
- 屏幕联动最后一轮没有再重启 Windows 和投影仪；配置了自启，不等于重新实测了整机启动。
- 没有主动更改 DHCP 地址做一次真实换 IP 测试；验证的是无固定 IP 配置、广播发现及重启电脑后台后的重新发现。
- 没有完整执行最终“全部恢复”流程；恢复脚本有语法与依赖检查，服务停止/启动另有实测。
- 预编译后没有测得显著启动提速，也没有证明桌面 FPS 有提升。
- 发现配置和辅助函数，不等于每个厂商限制都已实测触发。
