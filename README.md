# 当贝 Z7X PRO 折腾记录

记录一台投影仪从 ADB 安装应用，到音量细调、第三方桌面、语音增强和电脑屏幕联动的实际过程。重点是哪些真的做到了，哪些只是装上了，哪些试过以后发现没什么用。

这不是通用刷机包，也不是“所有当贝机型通用”的一键优化脚本。设备按日常名称称为 Z7X PRO，但系统上报 **D7XPG / Product_mudanpro2 / goat_elegant**。实测环境为 **Android 13、固件 v6.11.3、32 位 ABI、约 2 GB 内存**。其他型号或固件需要重新核对接口。

最后整理：**2026-11-07**。

## 我想解决的事

- 遥控器音量每按一次只变 1，显示真实的 0～100，而不是粗糙的十几档。
- 按 Home 直接进入自己安装的当贝桌面；重启和清理任务后也能继续用。
- 语音能真正调光源亮度、打开应用，完成后自己退出。
- 电脑同时接笔记本内屏、显示器、投影仪时，按投影仪实际信号源选择唯一工作的屏幕。
- 查明桌面卡顿、打开软件慢，以及固件额外加了哪些限制。

## 现在做到哪了

| 项目 | 结果 | 验证边界 |
|---|---|---|
| Google 框架、Play 商店 | 已安装 | 不等于设备获得 Google/Widevine 认证 |
| Apple TV | 已安装、能从桌面启动 | **播放失败没有解决**，不能写成“已可用” |
| 电脑代理开关 | 已实现打开启用、后台保留、手动关闭 | 系统 HTTP 代理，不是所有应用都强制经过的 VPN |
| 音量 0～100，每次 1 格 | 已实现 | 实体遥控、长按、跨重启均做过验证；0 为静音 |
| Home 直达第三方桌面 | 已实现 | 持久 HOME 规则与开机补充切换；用户确认可用 |
| 清理任务后音量失效 | 已修复 | 前台服务、自恢复、隐藏最近任务；手动“强行停止”仍是边界 |
| 语音调光源 1～10、打开应用 | 已实现 | 实体语音和执行反馈已确认，面板自动关闭已确认 |
| 语音增强自动加载 | 已实现 | 整机重启、原助手进程重启后的重新加载均读回确认 |
| 语音切 HDMI | **未完成实机确认** | v5 代码已加载，随后停止继续测试，不把它算作验证成功 |
| 按实际信号源切换电脑屏幕 | 已实现 | 局域网发现，断开 ADB 后往返测试通过；Windows 登录自启已配置 |
| 系统流畅度 | 做了小范围调优 | **没有测得明显提速**，不吹“一键起飞” |

完整验证表见 [验证状态](docs/00-status.md)。

## 最后确定的屏幕规则

```text
投影仪在系统 / Android 应用中 → 只有外接显示器工作
投影仪手动切到电脑的 HDMI 1 → 只有投影仪工作
笔记本内屏                    → 正常情况下关闭
```

一开始只保存 Windows 的显示布局，后来发现“投影仪在线”和“正在显示电脑 HDMI”不是同一回事，于是改成读取投影仪的实际状态。最终使用现有 Android 后台加电脑小程序，通过局域网自动发现，不依赖固定 IP 或长期 ADB 连接。详见 [屏幕联动](docs/04-display-router.md)。

## 仓库里有什么

- `sources/android-tv-remote/`：自写的“遥控优化”2.3 源码，包含音量服务、开机恢复、局域网状态应答。
- `sources/windows-display-router/`：自写的 Windows 显示配置与联动程序。
- `sources/voice-enhancement/`：自写的语义解析与助手运行时补丁源文件，保留测试用例。
- `tools/`：HOME 配置辅助代码和本地构建入口。
- `data/`：脱敏后的测试数字；不是原始用户日志。
- `examples/`：没有真实密钥的配置示例。

不包含厂商 APK、固件镜像、厂商反编译源码、Frida 可执行文件、Android SDK、签名私钥、订阅、真实配对文件或原始设备快照。工具源码可阅读，但它们不是已经适配好任意机器的安装器。

实现过程中使用了 Codex 协助分析和编写工具。这里区分脚本读回、静态检查和实体操作确认，避免把“代码写好了”当成“实机没问题”。

## 关于复现

先看适用环境、恢复方法，再看实现。音量方案同时依赖键位文件和无障碍服务，**不要只卸载工具而不恢复键位**。语音补丁依赖原助手版本和本机接口；不能照搬到另一台机器后假定安全或有效。

公开内容的取舍见 [SECURITY.md](SECURITY.md)，第三方工具来源见 [THIRD_PARTY.md](THIRD_PARTY.md)。本仓库未附带新的通用软件授权许可证；公开可见不代表可以忽略第三方组件各自的授权。
